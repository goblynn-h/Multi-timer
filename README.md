# 多任务计时器

## 简介

这是我在准备考研期间用Gemini和Deepseek生成的用于同时为多个学习任务计时Web应用程序，适合需要同时记录多个项目时间的场景。

## 主要功能

一、计时

可同时创建多个任务进行计时，支持秒级精度

二、任务管理

可以添加、删除任务，为每个任务添加备注，可重命名任务，可通过拖动排列任务顺序，可手动修改时间

三、数据管理

- 所有数据自动保存到浏览器本地存储，关闭浏览器后重新打开，数据依然存在
- 支持数据导出导入，可在不同浏览器间迁移
- 提供一键清除数据选项

四、报告生成

可生成Markdown格式的当日报告，报告内容自动复制到剪贴板，包含每个任务的时间统计、总时长和备注信息
