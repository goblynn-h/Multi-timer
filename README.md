# 多任务计时器

## 简介

这是我在准备考研期间用Gemini和Deepseek生成的Web应用程序，用来记录每天各科目学习时长。它应该也适用于需要同时记录多个项目时间的场景。代码没检查过（看不懂），但是能用。

## 主要功能

一、计时

可同时创建多个任务进行计时，支持秒级精度，可手动修改时间

二、任务管理

可以添加、删除、重命名任务，可以拖动卡片排列任务顺序，可以为每个任务添加备注

三、数据管理

- 所有数据自动保存到浏览器本地存储，关闭浏览器后重新打开，数据依然存在
- 支持数据导出导入，实现在不同浏览器间迁移
- 可一键清除所有数据

四、报告生成

可生成Markdown格式的当日报告，报告内容自动复制到剪贴板，包含每个任务的时间统计、备注信息以及总时长
